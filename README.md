# Networking Labs

Hands-on networking labs built while studying for CompTIA Network+ (N10-009), using Cisco Packet Tracer and my home lab (GNS3, Cisco Packet Tracer, VirtualBox). Each lab includes real configuration, troubleshooting notes, and verification steps — not just working configs, but the process of getting there.

## Labs

| Lab | Topics | Status |
|---|---|---|
| [GRE Tunnel Lab](gre-tunnel-lab/) | GRE encapsulation, static routing, WAN concepts, VPN tunneling | ✅ Complete |

More labs will be added here as I work through Network+ topics (VLANs, OSPF, subnetting, DMVPN/mGRE in GNS3, etc.).

## About

I'm transitioning into cybersecurity (targeting SOC Analyst / Threat Hunting roles) and building this repo alongside my certification roadmap: Network+ → Linux+ → Security+ → CySA+. Strong networking fundamentals underpin most defensive security work — understanding how traffic normally moves is what makes anomalies recognizable.
